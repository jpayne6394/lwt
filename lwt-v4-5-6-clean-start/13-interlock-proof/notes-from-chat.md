# Notes From Chat — Interlocking System

The mockup is the source of truth. Graphics must support the locked page structure, not invent a new layout.

The goal is an interlocking system:

- separate section assets
- shared seam geometry
- graphics flow through the page tastefully
- one major swoop/curve moment, especially Hero to Story
- trust/proof bar is coded, not baked into background art
- cards, buttons, text, stats, model rail, and product modules are coded HTML/CSS
- graphics are background/support only

Key phrase:

> Build a coordinated wrapper system where sections have controlled visual handoffs and shared flow language, so the page reads as one composition.

For this first proof, only test the Hero and Story slices from one master canvas.
