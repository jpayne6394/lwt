# LWT V4.5.6 About Source Reference Pack for Codex

This pack contains the actual PNG references currently approved/provided in the chat for the About page graphics planning pass.

## Critical rule

Do not treat every image in this pack as a final background slice.

The full-page and section-cut images are layout/reference images. They show the desired structure, section placement, and content zones.

The only explicitly approved art direction PNG in this pack is:

`04_approved_art/approved-practitioners-biotech-molecule-helix.png`

That approved art is for the Meet the Practitioners section visual language:
- helix
- molecule
- health science
- biotech
- signal/orbit accents
- no floral

## Background graphics rule

The final About page background should be created as a coordinated background system behind HTML/CSS content.

Do not bake into the art:
- text
- cards
- buttons
- practitioner cards
- product cards
- trust stats
- model icons
- footer columns
- navigation/header

## One-wave rule

Use one major wave/interlock only:
Hero bottom → Story / Company Bio top.

The rest of the page should connect through tasteful motif rhythm, accents, and shared visual language, not repeated big waves.

## Floral rule

Floral/botanical motifs are allowed only in the Catalog / supplement-related part of the 3-way funnel section.

Do not use floral in:
- Hero
- Company Bio
- Trust strip
- Meet the Practitioners
- Model
- Technology side
- Final CTA

## Codex role

Codex should not invent final art unless explicitly instructed. For now, this is a reference/source pack for planning and local preview work.
