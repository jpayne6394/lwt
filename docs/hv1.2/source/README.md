# HV1.2 Source Folder

This folder is reserved for approved visual source material.

## Required Target File

The approved homepage target image should be saved here as:

`homepage-target.png`

Codex should use that image as the visual reference for HV1.2 homepage work.

## Current Rule

If `homepage-target.png` is not present, Codex must not claim an exact visual match. It should continue with structure/audit work only, then report that the target image needs to be added.

## Accepted Source Types

- approved homepage target image
- approved section references
- approved production background slices
- approved mobile references
- safe-zone references

## Not Accepted as Final Implementation

A source image is a reference. It should not be used as a single flat live page. The final Hydrogen page should use live components and versioned assets.
