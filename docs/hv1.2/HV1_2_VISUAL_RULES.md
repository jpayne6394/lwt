# HV1.2 Visual Rules

Use this file before visual implementation.

## Direction

Premium warm wellness, deep navy, cream/off-white, warm gold, amber signal accents, subtle science motifs, and calm store layout.

## Keep

- live React content
- real Shopify data when available
- section order from `HV1_2_SECTION_MAP.md`
- quiet negative space for headings and calls to action
- balanced dark and light fields

## Avoid

- new visual concepts
- generic template look
- loud decorative clutter
- all-dark page treatment
- using one flat image as the entire page
- unsupported store content

## Special Rule

The large gold wave belongs near the About and booking transition, not in the main hero.

## Missing Work

When an asset or data source is missing, report it in the done message.
