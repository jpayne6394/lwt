# LWT V4.5.6 About Background System

Local preview only. This folder is a visual approval workspace for the About page background graphics system.

No Shopify files were touched. No commit or push is part of this preview. The assets here are candidates for visual approval and are not approved production assets until the user gives explicit production signoff.

## Preview

Open `index.html` through a local static server. The preview stacks the exported PNG background assets and overlays safe-zone boxes only. It does not include final copy, cards, buttons, practitioner portraits, product bottles, stats, navigation, footer content, or Shopify implementation code.

## Folder Contents

- `assets/desktop/`: desktop section exports and full-page master.
- `assets/mobile/`: mobile section exports and full-page master.
- `assets/reference/`: copied source references and approved art sources.
- `assets/safe-zones/`: desktop safe-zone overlay PNGs for review.
- `docs/`: art direction, motif map, safe-zone rules, export manifest, and QA checklist.
- `screenshots/`: required viewport captures for review.

## Scope Boundary

This folder is for background graphics only. The actual About page layout and HTML/CSS content integration will happen later, after final visual approval.
